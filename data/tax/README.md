# 세무 사례 데이터 — 개인사업자 부가가치세 간이과세 적용 여부 (10장)

이 폴더는 책 10장 "전문 업무로 확장: 세무 상담 사례"의 설계 데이터입니다. 앞 장의 노트클라우드 데이터(`data/eval`, `data/ontology`)와 같은 형식을 세무 상담에 적용해 본 것으로, **설계안과 데이터 파일만 있고 파이프라인으로 검증하지는 않았습니다.** 어디까지 확인했는지는 10-5에 표로 정리했습니다.

## 가상 데이터 고지

- 납세자 T001~T010, 금액, 개업일, 업종 조합은 모두 **가상**입니다. 실제 상담 기록·납세자 정보를 쓰지 않았고, 특정 인물을 추정할 수 있는 금액·날짜 조합을 피했습니다.
- 이 데이터는 "판단 구조를 설계하는 방법"을 보여 주기 위한 것입니다. 개별 납세자의 세무 판단에 그대로 쓰지 마십시오. 실제 판단은 세무 전문가와 최신 법령을 확인해야 합니다.

## 사례 범위

주제를 **개인사업자의 부가가치세 간이과세 적용 여부** 하나로 좁혔습니다. 이유는 노트클라우드 환불 규정과 같은 구조가 모두 들어 있기 때문입니다.

| 노트클라우드에서 본 구조 | 간이과세 판단에서 대응하는 것 |
|---|---|
| 규정 판(1판 → 2판)과 시행일 | 기준 금액의 판: 4,800만원 → 8,000만원(2021-07-01) → 1억 400만원(2024-07-01) |
| 예외(프로모션, 학생 요금제 준용) | 부동산임대업·과세유흥장소는 4,800만원 기준 유지, 배제 업종(광업·제조업·도매업 등) |
| 같은 말 다른 뜻(해지 vs 환불) | 공급대가(부가세 포함) vs 공급가액(부가세 제외) vs 매출액 |
| 정보 부족 시 보류(미사용 vs 미확인) | 신규 사업자의 12개월 환산, 겸업·복수 사업장 합산에 필요한 추가 정보 |
| (노트클라우드에 없던 것) | 전문가 사이에 해석이 갈리는 지점 |
