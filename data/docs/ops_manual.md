# 고객지원 운영 매뉴얼 — 환불·해지 처리

내부 문서. 2025년 7월 1일 개정.

## 1. 요청 접수 시 확인할 정보

환불 요청을 접수하면 다음 정보를 확인한 뒤 판단합니다. 하나라도 확인되지 않으면 결론을 내리지 않고 고객에게 확인을 요청합니다.

| 확인 항목 | 확인 방법 | 왜 필요한가 |
|---|---|---|
| 결제 완료일 | 결제 내역 | 전액 환불 기간 계산, 적용 규정 판 결정 |
| 결제 주기(월간/연간) | 구독 정보 | 적용 조항이 다름 |
| 요금제 | 구독 정보 | 팀·학생 요금제는 별도 조항 |
| 프로모션 코드 적용 여부 | 결제 내역 | 환불 제외·제한 대상 |
| 사용 여부(문서 생성 수, 로그인 횟수) | 사용량 조회 | 월간 구독 전액 환불의 "미사용" 판정 |
| 요청자가 팀 관리자인지 | 팀 정보 | 팀 요금제는 관리자만 요청 가능 |
| 계정 정지 여부 | 계정 상태 | 정지 계정은 환불 제외 |

## 2. 적용 규정 판 결정

1. 결제 완료일이 2025년 6월 30일 이전이면 환불 규정 제1판, 2025년 7월 1일 이후면 제2판을 기본으로 적용합니다.
2. 제1판 대상이라도 제2판이 고객에게 유리한 조항(연간 전액 환불 기간 30일, 위약금 폐지 등)은 이용약관 제9조 제3항에 따라 제2판을 적용합니다. 이 경우 처리 기록에 "약관 9조 3항 적용"을 남깁니다.
3. 자동 갱신 결제는 갱신 결제일을 결제 완료일로 봅니다.

## 3. 승인 권한

| 환불 금액 | 승인자 |
|---|---|
| 10만원 이하 | 상담원 |
| 10만원 초과 50만원 이하 | 팀장 |
| 50만원 초과 | 운영 책임자 |

규정에 없는 예외 환불(고객 불만 대응 등)은 금액과 관계없이 운영 책임자 승인이 필요합니다.

## 4. 용어 사용 지침

상담 기록과 고객 안내에서 다음 용어를 구분해 씁니다.

- 해지: 다음 주기부터 갱신 중단. 금액 반환 없음.
- 환불: 금액 반환. 환불 규정 적용.
- 결제 취소: 결제 후 24시간 이내 철회. 환불 규정 미적용, 승인 취소 처리.
- 크레딧: 다음 결제에서 차감되는 보상. 현금 반환이 아님.

고객이 "취소해 주세요"라고 하면 해지·환불·결제 취소 중 무엇을 원하는지 먼저 확인합니다.

## 5. 장애 크레딧 처리

1. 장애 관리 시스템에 등록된 장애 중 연속 24시간 이상인 건만 보상 대상입니다.
2. 크레딧 금액 = 월간 환산 요금 × (장애 시간 / 720시간). 연간 결제 고객은 연간 금액을 12로 나눈 값을 월간 환산 요금으로 봅니다.
3. 공지된 정기 점검은 장애로 등록하지 않습니다.

## 6. 규정 변경 시 재점검

환불 규정이 개정되면 다음 대상을 재점검합니다.

1. 개정 시행일 기준으로 진행 중인 환불 요청
2. 개정 전 결제된 구독 중 개정 조항이 고객에게 유리하게 적용될 수 있는 구독
3. 상담 스크립트와 FAQ의 관련 문구
